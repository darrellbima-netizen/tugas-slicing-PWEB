DESERTO - Tugas Slicing Website

DESERTO adalah website sederhana untuk menampilkan menu makanan dan minuman. Website ini dibuat sebagai tugas Slicing Website menggunakan HTML, CSS, dan JavaScript.
Website menyediakan beberapa menu dan bisa difilter berdasarkan tipe menu yang ada, untuk menu yang ada sendiri di website ini adalah Minuman dan Desert

## Bahasa Coding yang Digunakan
- HTML
- CSS
- JavaScript

## Fitur
- Tampilan menu makanan dan minuman
- Filter menu berdasarkan kategori
- Interaksi menggunakan JavaScript
- Tampilan responsive
